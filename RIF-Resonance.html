How to install and unlock

  1. Open this page in Safari and choose your device’s app button.
  2. In Safari, tap Share → Add to Home Screen to install the RIF Resonance icon.
  3. Return to this page and download your device’s script ZIP.
  4. Open Files → Downloads, tap the ZIP to extract it, then select the .riflibrary file from inside RIF Resonance.

iPhone and iPad do not install apps from ZIP files. RIF Resonance installs from Safari as a secure Home Screen web app; the script library remains a separate download.
